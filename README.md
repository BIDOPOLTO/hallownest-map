# Hallownest Map – Federico

Mappa interattiva personale di Hollow Knight, senza account obbligatori e senza tracking.

## Stato
Repository gestito direttamente da ChatGPT per il progetto RP6.

## Funzioni previste
- pan/zoom mouse, touch e pinch
- marker community con filtri
- ricerca
- trovato/non trovato
- note personali
- progress tracker
- modalità anti-spoiler
- salvataggio locale
- export/import JSON

La mappa usa tile pubblici di ScriptersWar/Hallownest.net e dati community pubblicamente accessibili. Hollow Knight è © Team Cherry. Progetto personale e non commerciale.
